# ConerZone AI Movie Recap Studio

A beginner-friendly starter project for a web-based movie recap studio.

## Planned features
- Recap script workspace
- Subtitle editing and SRT export
- Voice-over workflow
- Video import and preview
- Export workflow

## Current status
This repository is the starter foundation only. AI processing, media rendering, authentication, and Android packaging still need to be implemented and tested.

## Development
The first version will use Next.js and TypeScript. Never commit API keys or secrets. Put private environment variables in `.env.local` and keep that file out of Git.

## Copyright note
Only upload or process video that you own or are authorized to use. Recap narration, cropping, blurring, or subtitles do not automatically grant permission to reuse copyrighted footage.
